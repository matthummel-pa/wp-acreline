Child theme for Acreline. Put CSS here so parent updates do not wipe it.

== Description ==

Acreline Child loads after the Acreline parent (`Template: acreline`). Edit `style.css` or `functions.php` in this folder only.

The parent folder must stay `acreline`. This child is GPLv2 or later.

== Installation ==

1. Install and activate the Acreline parent theme first.
2. Upload `acreline-child` to `/wp-content/themes/` (or upload the zip from Appearance → Themes).
3. Activate Acreline Child.
4. Add CSS below the comment in `style.css`.
