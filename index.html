Installation

Up and running in minutes

No Composer. No npm. The zip ships with compiled assets and a production vendor/.

1
Extract the outer zip
Your purchase downloads acreline-*.zip. Extract it — do not upload the outer file directly into WordPress.
2
Upload the inner acreline.zip
Appearance → Themes → Add New → Upload Theme. Choose the inner acreline.zip and activate. The folder must stay acreline.
3
Run the Setup Wizard
Appearance → Acreline Setup. Five steps: brand name, phone, color style, optional demo content, done.
4
Fine-tune Identity
Appearance → Customize → Identity — phone, email, address, hours, header CTA, logo. These drive the header, footer, and booking form.
5
Enable the top bar (optional)
Appearance → Customize → Top Bar. Add an announcement, contact items, social icons, or a CTA pill — live preview included.
6
Upload optional extras
Upload acreline-child.zip (CSS that survives parent updates) and acreline-core.zip (listings that survive a theme switch).

FAQ

Common questions

Can I use this with real MLS listings?
Yes — every listing is a WordPress CPT. Enter your actual property data in the metaboxes. The fictional demo data is pre-seeded for illustration only. Delete it before going live.
Does the mortgage calculator need an API key?
No. It runs entirely in the browser using standard amortization math. No third-party service, no API key, no tracking.
Can I rename "Township" to "County" or "Neighborhood"?
Yes — open Theme Settings → Labels and change the Township / area label. The new label appears on listing cards and detail pages immediately.
Where are showing requests stored?
Showing requests become Booking CPT posts in WordPress Admin → Bookings. No external CRM by default — all data stays in your database.
Does the top bar show on mobile?
The bar itself is hidden below 900 px. Everything you enable in the top bar — announcement, contact details, social icons, CTA — automatically surfaces at the foot of the slide-out mobile nav drawer so nothing is hidden from mobile visitors.
How do I update the theme after purchase?
Our CI workflow builds a fresh zip on every push to main. Paste a fine-grained GitHub PAT (Contents: Read) into Appearance → Customize → GitHub, then go to Appearance → Update Theme and click Install latest zip from GitHub. Pages and content are untouched.
Do I need ACF, Elementor, or a page builder?
No. Listing, agent, and booking fields are all native WordPress metaboxes. Pages are built with 32 custom Gutenberg blocks. No page builder is required or recommended.
What plugins are required?
None. The theme zip is self-contained. Optional Acreline Core keeps listings if you ever switch themes. Optional Acreline Child lets you add custom CSS that survives parent updates. No other plugins are needed.
