# Acreline brand kit

Canonical product brand for the Acreline WordPress theme. Use this when you ship the demo, ThemeForest assets, matthummel.com product landing, or client handoff.

## Name

**Acreline** — one word, title case. Not “Acre Line,” not “Keystone.”

Retired demo name **Keystone** (and `@keystone-concept.test`) must never appear in buyer-facing copy. The theme’s `Identity::isRetiredBrand()` falls back to Acreline when those strings are still in old Customizer or seed data.

## Tagline

**Farms · land · historic homes**

Short header line under the wordmark. Alternate for long-form:

> WordPress theme for rural offices — searchable listings, agents, and showing requests.

## Voice

Plain, survey-clear, land-office honest. No luxury-gold realtor clichés. Fiction demos stay labeled as fiction (555 phones, `@acreline-concept.test`).

## Forest sample palette (default)

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#141210` | Body text, mark tile |
| Paper | `#f5f4f1` | Page background |
| Accent (Forest) | `#1f6b4a` | Buttons, links, roof |
| Accent dark | `#155539` | Hover / roof shade |
| Door / card light | `#fffcf7` | Mark door, soft fills |
| Card | `#ffffff` | Listing and agent cards |

Eight Customizer styles: Forest, Clay, Navy, Burgundy, Harvest, Lake, Orchard, Charcoal. Forest is the sample office on the live demo.

## Type

Live theme: **Inter** (SIL OFL). Documentation wordmark may use Georgia for the “Acreline” text in the SVG lockup only.

## Where identity is set

| Surface | Control |
| --- | --- |
| Live demo | [acreline.matthummel.com](https://acreline.matthummel.com/) → Customize → Identity |
| Buyer installs | **Appearance → Customize → Identity** (+ Site Identity logo) |
| Product landing | [matthummel.com/projects/acreline/](https://matthummel.com/projects/acreline/) |
| Own-site checkout | WooCommerce product **Acreline WordPress Theme** on matthummel.com |

## Do not

- Claim the sample office is a licensed brokerage or live MLS
- Ship Keystone naming in screenshots, titles, or footer copy
- Put real client phones on the public demo
- Paste NAR / HUD / MLS logos into the pack
