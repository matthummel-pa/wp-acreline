Acreline ships with a set of built-in tools that most real estate themes charge extra for — or require a plugin to unlock. Here is what is included and how each one works.

Compare listings side-by-side

Every listing card on the grid page has a Compare button. Select up to three properties and a full-screen modal opens with a column for each: price, beds, baths, square feet, acreage, MLS number, township, and status. No third-party widget, no API, no account required — the comparison runs entirely in the browser using data already on the page.

  • Tap the Compare button on any card
  • Select a second and third listing to activate the modal
  • Clear the selection and start over at any time

Save listings across visits

The heart icon on every card saves a listing to the browser's local storage — no login, no email address, no account creation. A floating button in the corner shows how many properties are saved and opens a slide-out drawer with thumbnails, prices, and direct links. The list persists across page loads and visits until the visitor clears it.

Sticky CTA bar on every listing

After a buyer scrolls past the hero photo on a single listing page, a slim bar locks to the top of the window with the list price and a "Book a showing" button. The bar appears and disappears smoothly. On reduced-motion devices the animation is skipped. Sellers and agents benefit from one persistent call to action without cluttering the detail page.

Share and print

The Share button on every listing page uses the browser's native share sheet on mobile — the same UI used by email and messaging apps. On desktop it copies the URL to the clipboard and confirms the copy inline. The Print button generates a clean one-page flyer with the photo, price, key stats, and description — ready for a PDF printer or a direct printout to leave at a property.

Recently viewed and nearby listings

The last five listings a visitor opened are tracked in local storage and appear as clickable chips at the bottom of each detail page. This keeps buyers moving through inventory without returning to the grid every time. Separately, the Nearby Listings section pulls up to three other active properties in the same township from the WordPress database — no map API, no subscription required.

Built-in mortgage calculator

Each listing detail page includes a payment estimator with an editable purchase price, interest rate, down payment percentage, and loan term. The monthly payment updates on every keystroke. The default rate is set in Appearance → Acreline Settings → General. No plugin, no third-party script, no API key.

Market snapshot shortcode

Enter your area's median sale price, average days on market, months of inventory, and year-over-year price change in Appearance → Acreline Settings → Market. Then embed [acreline_market_snapshot] on any page or post — the home page, a blog sidebar, or a dedicated market report page. The stats strip updates across the site from one place.

Rich listing detail sections

Each listing supports far more than price and beds. The metabox in the admin includes sections for property condition, garage type, basement, roof age, HVAC, water and sewer source, utilities, HOA dues, land mineral and timber rights, road frontage, perc status, flood zone, school district, green certifications (Energy Star, LEED, solar), and smart home features. Each section can be toggled site-wide in Theme Settings so you only show what is relevant to your market.

Advanced agent profiles

Agent pages show a performance stats grid with homes sold, total volume, and average days on market. Below that: social media links (Facebook, Instagram, LinkedIn, YouTube, X/Twitter), certifications and designations, a personal website link, an intro video link, and a calendar booking button. All sections are individually toggleable in Appearance → Acreline Settings → Agents.

Where to go next

Walk through Appearance → Acreline Support to see all features in one place, read the FAQ, and find the shortcode reference. Use Appearance → Acreline Settings to turn features on or off per section. All inventory is in WordPress Admin → Listings; all agent records are in WordPress Admin → Agents.
