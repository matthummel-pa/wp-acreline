Support

Acreline is a WordPress theme for farms, land, and historic homes. Sample listings and showing requests are concept data — not a live MLS or licensed brokerage. Created by Matt Hummel.

ThemeForest / Envato item support follows that marketplace’s channel and hours. GitHub issues are welcome for reproducible theme bugs: matthummel-pa/wp-acreline. There is no ticket desk or live chat in the theme.

Before you write

  1. Theme folder is still acreline. Store zips include public/build.
  2. Identity and colors are under Customize — not in page content.
  3. Listings and agents are WordPress posts. Editing a PHP file does not change live copy.
  4. Include WordPress version, PHP version, theme version (Appearance → Themes), and whether Acreline Core is active.

Demo phones are 555 numbers (office (555) 010-0455). @acreline-concept.test does not reach a real inbox.

What this theme does not do

  • Sync a live MLS or IDX feed
  • Process payments or hold real appointments
  • Replace a licensed brokerage or CRM
  • Ship Gutenberg / block-editor patterns
  • Require ACF, Elementor, or a page builder

Security

Do not commit GitHub tokens. The updater PAT lives in Customizer → GitHub, Appearance → Update Theme, or KS_GITHUB_TOKEN on the host. Contents: Read to install the zip. Add Actions: Read and write only to trigger rebuilds. Repo: matthummel-pa/wp-acreline.
