## Long description (HTML-ish; Envato accepts markup)

```html
<h2>Rural inventory, not another luxury brokerage skin</h2>
<p>Acreline is a WordPress theme for offices that sell <strong>acreage, working farms, and historic homes</strong>. Buyers search sample listings, open a property, meet an agent, and request a showing. Identity, colors, and the header live in the Customizer.</p>

<p><strong>Fiction only.</strong> The live preview uses 555 phone numbers and <code>@acreline-concept.test</code> emails. It is not a live MLS, licensed brokerage, or booking desk.</p>

<h3>What you get</h3>
<ul>
  <li>Homepage search → listings with type, price, acreage, and area filters</li>
  <li>Grid and map views from the Listings post type</li>
  <li>Showing requests saved as Booking posts (Requested → Confirmed → Completed)</li>
  <li>Agents page and singles (license, MLS/NRDS, specialties, contact)</li>
  <li>Areas, land-buyer guide, contact, and blog templates</li>
  <li>Customizer identity: brand, phone, email, address, hours, header button, removable author credit</li>
  <li>Eight color styles (Forest, Clay, Navy, Burgundy, Harvest, Lake, Orchard, Charcoal) plus accent, paper, and ink</li>
  <li>Header size and sticky toggle; Inter-based typography with font choices</li>
  <li>WordPress Primary + Footer menus, custom logo, footer widgets, breadcrumbs</li>
  <li>Native title, description, Open Graph, and Twitter tags (yields to Yoast / Rank Math / SEOPress / AIOSEO)</li>
  <li>Translation-ready text domain <code>acreline</code></li>
</ul>

<h3>What is in the download</h3>
<ol>
  <li><code>acreline.zip</code> — upload this in Appearance → Themes. Keep the folder named <code>acreline</code>.</li>
  <li><code>acreline-child.zip</code> — optional child theme.</li>
  <li><code>acreline-core.zip</code> — optional plugin so listings survive a theme switch.</li>
  <li><code>Documentation/</code> — HTML docs (open <code>index.html</code>).</li>
  <li><code>Demos/</code> — seed notes (Tools → Seed Acreline demo).</li>
  <li><code>Licensing/</code> — GPLv2 notice and credits.</li>
</ol>
<p>Do not upload the outer pack zip into WordPress. Extract it first.</p>

<h3>Requirements</h3>
<ul>
  <li>WordPress 6.6+</li>
  <li>PHP 8.3+</li>
  <li>No Composer or npm on the host — the zip already includes <code>vendor/</code> and <code>public/build/</code></li>
  <li>Classic editor / metaboxes. Not Gutenberg-optimized. Not Elementor.</li>
</ul>

<h3>Credits</h3>
<p>Fonts load from Google Fonts (SIL OFL). Sage / Acorn remain MIT. Theme code is GPLv2 or later. Unsplash photographs used on the demo are hotlinks and are <em>not</em> bundled.</p>
```
