Keep CSS through parent updates

The pack includes acreline-child.zip. Activate it after the parent so WordPress still finds templates in acreline.

Theme NameAcreline Child
Templateacreline (must match the parent folder)
Text domainacreline-child

What to edit

  • Put CSS overrides in the child style.css. Parent styles already load from compiled Sage assets; the child file is extra.
  • Add PHP in the child functions.php (hooks only — do not copy the parent file).
  • Do not edit parent Blade or PHP if you want clean updates from the theme-latest zip or a new marketplace download.

Install

  1. Appearance → Themes → Add New → Upload Theme → acreline-child.zip.
  2. Activate Acreline Child.
  3. Re-assign menus if WordPress dropped them (rare; check Appearance → Menus).

Folder name

The parent folder must stay acreline. Renaming it breaks Vite asset URLs and the child Template: header.
