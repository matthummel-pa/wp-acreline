Header

  • Header size — Standard or Compact (shorter bar on listing-heavy pages).
  • Stick the header while scrolling — on by default.

Typography

Sans-serif families loaded from Google Fonts when selected. Inter is the default for headings, body, nav, buttons, and labels. Base size 14–20px (16 default). Heading weight 500 / 600 / 700.

Families: Inter, Plus Jakarta Sans, DM Sans, Manrope, Montserrat, Poppins, Source Sans 3, Nunito Sans, Outfit, Lato. All SIL OFL. No font files are vendored in the zip.

Social links

Facebook, Instagram, YouTube, LinkedIn, X / Twitter. Empty fields stay hidden. Output is in the footer social partial.

GitHub (author installs)

Customize → GitHub holds an optional personal access token for Appearance → Update Theme. Buyers on ThemeForest do not need this. Never commit a token into theme files.
