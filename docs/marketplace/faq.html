Frequently asked questions

Install

Where do I change the phone number?

Appearance → Customize → Identity.

How do I hide the concept demo banner?

Customize → Identity → uncheck “Show concept demo banner and author badge.” Uncheck the credit box to drop the footer author line. WordPress.org expects the buyer’s copyright only.

The theme folder was renamed and styles broke.

Rename it back to acreline. Compiled CSS/JS URLs use that path. Do not install the outer pack zip as a theme.

White screen after upload?

Confirm PHP 8.3+ and that you uploaded the inner acreline.zip (it must contain style.css, functions.php, vendor/, and public/build/). After Blade edits on a source checkout, run wp acorn view:clear.

Editor

Where is Gutenberg / Elementor?

Not included. Gutenberg optimized = No. Pages, listings, and agents use classic metaboxes on purpose.

Can I use a child theme?

Yes. The pack includes acreline-child. See child-theme.html.

Inventory

Where do listings live?

The listing post type. Acreline Core owns registration on a store install. The theme still registers the types when the plugin is missing so the concept site keeps working.

Does this sync a live MLS or IDX?

No. MLS numbers on sample cards are display-only. There is no RETS/Web API feed and no payment processor.

Book showing 404s with ?listing=123.

Use ?listing_id=123 (the listing post ID). See listings.html.

Do showing requests email the office?

No. They create a Booking post in Requested status. Demo emails at @acreline-concept.test do not reach an inbox.

SEO and credits

Can I use Yoast or Rank Math?

Yes. Native title / description / canonical / Open Graph / Twitter tags yield when those plugins are active.

Must I keep the author credit?

No. Uncheck it under Identity. The remaining footer line is the site name and year. The optional credit uses rel="nofollow".

Photos

Why are listing photos missing offline?

Concept photos are Unsplash hotlinks. They are not in the zip. Replace them from the Media Library on a client site.
