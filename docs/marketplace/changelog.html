  • Customizer — Appearance → Customize → Header: “Animate homepage hero image” (on) and “Tilt listing search on mobile” (off). The two checkboxes are independent.

1.4.0 — September 2026

  • Top bar — configurable slim bar above the header (Customize → Top Bar). Desktop-only (hidden below 900 px). Announcement badge + message, CTA pill, contact items (phone / email / address / hours), social icons, optional dismiss button. Four color presets: Dark, Accent, Light, Custom. All enabled items surface at the foot of the mobile nav drawer on small screens.
  • Agent List block — new acreline/agent-list Gutenberg block on the Agents page with photo, performance stats, designations, and social links.
  • Accessibility — focus trap on listing modal, saved drawer, and compare modal; aria-live screen-reader announcements for save and compare; dynamic aria-label on each button.
  • Responsive — listing detail grid, compare table, compare bar, mortgage calc grid, and saved drawer stack / scroll correctly on narrow phones.
  • Content — seed listings enriched with open house, virtual tour, utilities, HOA, school district, flood zone, outbuildings, and land acres. Seed agents enriched with stats, social, video, certifications, and awards.
  • Docs — README, readme.txt, CHANGELOG, themeforest-listing, changelog.html, and buyer-guide.html all updated. Version 1.4.0.

Re-test: Customize → Top Bar; desktop and mobile header; Agents page; listing modal keyboard navigation.
