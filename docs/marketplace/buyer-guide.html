Buyer guide

Acreline is a classic WordPress theme for real estate marketing sites. You install it like any theme, set colors and logo in the Customizer, and manage listings as a custom post type. This guide walks through a first launch without requiring a developer.

Requirements

  • WordPress 6.4 or newer
  • PHP 8.0 or newer (8.2+ recommended)
  • A classic theme-capable install (Acreline is not a block theme)

Optional: a caching plugin and an SMTP plugin for contact form delivery. Acreline uses wp_mail() for inquiries.

Install

  1. In wp-admin, open Appearance → Themes → Add New → Upload Theme.
  2. Upload the Acreline zip and activate the theme.
  3. Open Appearance → Acreline Setup and run the setup wizard (identity, colors, optional demo).
  4. Visit Settings → Permalinks and click Save (even if you change nothing) so listing URLs register cleanly.
  5. Create a primary menu under Appearance → Menus and assign it to the theme’s primary location.

After activation, Acreline can seed starter pages and a sample listing once. Existing content is left alone.

Brand and Customizer

Open Appearance → Customize. Look for the Acreline sections (names may vary slightly by version):

  • Colors — primary, accent, and supporting tones. Prefer brand colors your shop already uses on print or social.
  • Identity / logo — site title, tagline, and logo image. Keep the logo simple; it appears in the header on every page.
  • Homepage / hero — headline, supporting line, and call-to-action when you use the front page template.
  • Contact — phone, email, and office lines used in the footer and contact template.

Publish when you are done. Changes are live for visitors immediately after you click Publish.

Tip: Set a custom logo with a transparent background. Test the header on a phone-width window before you launch.

Listings

Listings are a custom post type. In wp-admin you will see a Listings menu (label may read Properties depending on version).

Add a listing

  1. Go to Listings → Add New.
  2. Enter the property title (street address or marketing name).
  3. Fill listing fields: price, beds, baths, square footage, status, and location as provided by the theme meta box.
  4. Set a featured image for the card and single header.
  5. Write the body copy in the editor. Keep paragraphs short for phone readers.
  6. Publish.

The public archive is typically at /listings/ (confirm under Permalinks if you customized structures). Each listing has its own URL for sharing.

Statuses and filters

Use status values the theme exposes (for example for sale, pending, sold) so archive filters stay accurate. Do not invent statuses in free text if a dropdown is provided.

Page templates

Acreline ships named page templates. Create a Page, then choose a template in the Page Attributes / Template panel:

  • Front page / Home — hero, featured listings, and primary CTA.
  • Listings — points visitors at the listing archive or a curated grid when configured.
  • About — story and trust content for the brokerage or agent.
  • Contact — inquiry form plus office details from the Customizer.

Under Settings → Reading, set your Front page to the Home page you created. Optionally set a Posts page if you also publish a journal.

SEO and sharing

  • Write a clear site tagline in Settings → General.
  • Give every listing a unique title and excerpt-friendly summary.
  • Add meaningful alt text on featured images (address or room type — not “image1”).
  • Pair Acreline with your preferred SEO plugin if you need schema beyond what the theme outputs.

Share listing URLs on social; Open Graph tags follow your title, excerpt, and featured image when supported.

Accessibility

  • Keep color contrast readable when you change Customizer colors (especially text on accent buttons).
  • Do not remove focus outlines with custom CSS.
  • Ensure the primary menu is keyboard reachable on desktop and mobile.
  • Contact forms should remain usable without a mouse.

What ships in the zip

A typical Acreline package includes:

  • Theme PHP templates and functions.php
  • Styles and scripts under the theme’s asset folders
  • Listing post type and meta registration
  • This docs/marketplace/ folder for buyers and reviewers

You do not need Node or Composer on the server for a classic build. Follow the zip’s README if a built CSS file must already be present.

FAQ

Can I use a page builder?

Acreline is built as a classic theme with its own templates. Heavy page builders may fight the layout. Prefer the bundled templates for the marketing pages.

Does Acreline connect to an MLS?

Not out of the box. Listings are managed in WordPress. MLS or IDX belongs in a separate plugin or integration if you need it later.

Is the sample content required?

No. Starter pages and a sample listing are optional helpers. Delete or replace them anytime.

Where do I get support?

Use the support channel listed on your marketplace purchase page or the theme author site. Include your WordPress and PHP versions when you write in.
