Install and match the demo

Acreline is a classic (non-block) WordPress theme for land, farms, and historic homes. Sample phones are 555 numbers. It is not a live MLS or licensed brokerage. Created by Matt Hummel.

Little plugin stack. The theme zip alone runs the office. You do not need Advanced Custom Fields, Elementor, a Gutenberg kit, or an IDX plugin. Change headlines, prices, and photos in Customizer + metaboxes — not in Blade or CSS.

1. Installation

  1. Host: WordPress 6.6+ and PHP 8.3+ (full table). Composer and npm are not required on the host.
  2. Extract the outer pack zip. Upload acreline.zip via Appearance → Themes → Add New → Upload Theme.
  3. Activate Acreline. The folder name must stay acreline (Vite asset URLs).
  4. Optional: activate acreline-child.zip, then acreline-core.zip.
  5. Appearance → Acreline Setup — run the setup wizard (identity, colors, optional demo).
  6. Customize → Identity — brand, phone, email, address. Site Identity — logo.
  7. Tools → Seed Acreline demo if you want the preview pages and sample inventory.

Do not upload the outer acreline-*.zip into WordPress. WordPress only accepts a zip whose root folder contains style.css.

Permalinks: Settings → Permalinks → Post name. Pretty permalinks are required for /listing/{slug}/ and /agent/{slug}/.

2. Plugins — none required

To go liveTheme only. Listings, agents, and bookings register in the theme so the demo works.
Acreline Core (optional)Keeps those post types in the database if you later switch themes. Store-correct home for CPTs. In this pack as acreline-core.zip.
Acreline Child (optional)CSS that survives parent updates. acreline-child.zip.
SEO (optional)Yoast, Rank Math, SEOPress, or AIOSEO. The theme already prints title, description, canonical, Open Graph, and Twitter tags and yields when one of those is active.
Do not install to “make fields work”ACF, Meta Box, Elementor, WPBakery, an IDX/MLS plugin, or a second SEO panel in the theme.
TGMPA / plugin installerNot used. This theme does not auto-install plugins.

WordPress.org / Theme Check: a future lite zip can define KS_DISABLE_THEME_CPTS so the theme is presentation-only when Core is the registrar. This general pack does not set that, so a regular host works with the theme zip alone.

3. Homepage and reading settings

  1. Seed creates a page titled Home with template Home (front-page.blade.php).
  2. Settings → Reading → A static page → Homepage: Home. Posts page: Blog.
  3. If the front page looks like a post list, Reading is still set to “Your latest posts.”

The homepage search form (type, price, acreage, area) submits to the Listings page with query params. Inventory is the listing post type — JavaScript reads window.KEYSTONE.listings.

5. Custom fields — do not edit the design

The block editor is off. Templates are Blade. Day-to-day copy is metaboxes on the post or page. Keys are stored as ks_{field} — do not rename them or live posts go blank. Allowed HTML in page copy: em, strong, br, a.

Photo fields use the media library (upload or pick). A URL is kept for existing Unsplash / hotlinked photos. Uploads also set the featured image.

Pages (Page fields)

Each marketing template has hero brand, eyebrow, title, lead, hero image, plus page-specific section copy and a bottom CTA. Empty fields fall back to theme defaults — you can clear a field to restore the sample sentence.

Bookings

The public showing form POSTs to keystone/v1/bookings and creates a Booking post. Pipeline: Requested → Confirmed → Completed (or Cancelled). Advance status from WP Admin → Bookings (row action or the metabox). Use /book/?listing_id=123 to preselect a listing. Do not use ?listing= as a public query (it 404s /book/).

Showing types: In-person tour, Private preview, Virtual walk-through. Fields: date, time, client name / email / phone, notes, assigned agent.

This is a concept pipeline — not a calendar, payment, or lockbox system.

Blog posts (Post fields)

Featured image + article body. The block editor is off; paste HTML in the body if you need links or lists.

Editing theme files does not change live posts. Re-seed only to reset sample inventory.

6. Menus, widgets, and logo

  1. Appearance → Menus — locations Primary Navigation (header) and Footer Navigation. Seed creates Home, Listings, Areas, Guide, Blog, Agents, Contact.
  2. Hardcoded concept slugs are the fallback only, before a menu is assigned.
  3. Appearance → Widgets — Footer (public) and Primary (sidebar). Classic widgets.
  4. Customize → Site Identity → Logo — replaces the house mark. See branding.
