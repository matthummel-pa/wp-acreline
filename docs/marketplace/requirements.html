Host needs and seller listing fields

This pack is for a regular WordPress install: Appearance → Themes → Add New → Upload Theme. The file to upload is acreline.zip. Leave the folder name acreline.

Acreline is a land-and-farms realtor concept theme. Sample phones are 555 numbers. It is not a live MLS, licensed brokerage, or booking system. Created by Matt Hummel.

1. Buyer — what the host must have

WordPress6.6 or newer (tested through 7.0.1)
PHP8.3 or newer (8.4 is fine)
PHP extensionsmbstring, xml, curl, zip, intl, json, plus gd or Imagick for media
Memory128 MB minimum; 256 MB recommended (Sage / Acorn)
HTTPSRecommended on any public site
Install folderMust stay acreline (compiled asset URLs use that path)
Composer / npm on the hostNot required. Store zips already include vendor/ and public/build/
Block editorNot used. Edit pages, listings, and agents through custom fields
Page builderNone required (not an Elementor / Gutenberg theme)
DatabaseMySQL / MariaDB as WordPress expects. SQLite is only for this repo’s local demo helper

Optional, not required

  • Acreline Core (acreline-core.zip) — keeps listings, agents, and bookings if the buyer later switches themes. The parent theme still registers those types when the plugin is off, so a regular install works with the theme zip alone.
  • Acreline Child (acreline-child.zip) — CSS that survives parent updates.
  • Yoast, Rank Math, SEOPress, or AIOSEO — the theme yields native title / OG tags when one of these is active.

This theme does not include

  • A live MLS / IDX feed or payment processor
  • Gutenberg patterns or a page-builder kit
  • Bundled Unsplash image files (concept photos are hotlinks; replace them on a client site)
  • A license lock, Freemius, or Envato purchase-code nag

2. Regular install (two minutes)

  1. WordPress 6.6+ and PHP 8.3+ on the host.
  2. Appearance → Themes → Add New → Upload Theme → acreline.zip → Activate Acreline.
  3. Optional: upload and activate the child theme, then Acreline Core.
  4. Appearance → Customize → Identity (brand, 555-style phone, email, colors).
  5. Tools → Seed Acreline demo if you want the preview pages and sample inventory.

Full walkthrough: buyer-guide.html. Help: support.html.

Long description (paste on the item page)

Acreline is a WordPress theme for rural real-estate offices: searchable listings, agents, and showing requests — built for farms, land, and historic homes, not a generic luxury-broker skin. Almost no plugins. The theme zip alone runs the office. You do not need Advanced Custom Fields, Elementor, a Gutenberg kit, or an IDX plugin. Brand, phone, colors, and inventory live in the Customizer and classic custom-field metaboxes, so you change headlines and prices without editing the design. Eight color styles (Forest, Clay, Navy, Burgundy, Harvest, Lake, Orchard, Charcoal). Custom logo. Primary + Footer menus. Footer widgets. Native title, description, Open Graph, and Twitter tags (yields to Yoast / Rank Math / SEOPress / AIOSEO). Translation-ready text domain acreline. Optional Acreline Core keeps listing / agent / booking post types if you later switch themes. Optional Acreline Child keeps CSS through parent updates. Both ship beside the theme zip, not inside it. Classic (non-block) on purpose. Gutenberg optimized: No. WooCommerce: No. Not a live MLS or licensed brokerage — the preview uses 555 phones and sample inventory. Documentation: open Documentation/index.html in this pack. Demo: https://acreline.matthummel.com/ — Matt Hummel, GPLv2 or later.
